## 2025-05-15 - Standardizing Quote Styles and Visual Cues
**Learning:** Replacing curly quotes (‘ ’) with standard straight double quotes (") improves technical accessibility (screen reader consistency) and copy-paste usability for CLI-integrated agent loops. Adding thematic emojis (🧠, ✨, 🧵) as prefixes/suffixes provides rapid visual orientation in dense LLM logs.
**Action:** Always prefer straight double quotes for machine-parseable or human-copied commands. Use brand-consistent emojis to categorize different types of agent "thoughts" or "invitations".
