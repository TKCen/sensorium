# Palette's Journal - Critical UX Learnings

## 2025-05-15 - Standardizing Quote Style for LLM Interactivity
**Learning:** Using curly quotes (‘ ’, “ ”) in CLI invitations and context pointers can hinder copy-paste usability and cause inconsistent parsing by LLMs when they are instructed to use specific phrases or commands. Straight double quotes (") are more robust and expected in technical/CLI contexts.
**Action:** Always prefer straight double quotes (") for suggested user phrases and internal instructions in context pointers.
