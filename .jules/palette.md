## 2025-05-15 - Standardize Quote Style for Usability
**Learning:** Using non-standard "smart" or curly quotes (‘ ’, “ ”) in CLI invitations or context pointers creates friction for users (copy-paste failures in terminals) and reduces LLM reliability in identifying command boundaries.
**Action:** Always prefer straight double quotes (") for commands, keywords, and suggested user responses in all human-facing and agent-facing text.
