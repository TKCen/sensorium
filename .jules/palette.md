## 2026-07-03 - Standardize quote style for copy-paste usability
**Learning:** Using curly quotes (‘ ’, “ ”) in CLI invitations or context pointers can hinder UX for developers and LLMs. They are often harder to copy-paste reliably into terminals and can cause parsing issues for LLMs that expect standard ASCII double quotes.
**Action:** Always prefer standard straight double quotes (") for commands, keywords, or phrases intended to be used as input by the user or the LLM.
