# Palette Journal - Critical UX/A11y Learnings

## 2025-05-14 - Standardizing Invitation Quotes and Visual Cues
**Learning:** Standardizing quote style (from curly ‘ ’ or “ ” to straight " ") in CLI invitations and context pointers improves copy-paste usability and ensures consistent LLM command parsing. Using emojis (🧠 for Sensorium, 🧵 for threads, ✨ for salience) provides immediate visual classification of attention types.
**Action:** Use straight double quotes for all actionable commands in invitations. Use established emoji cues for Sensorium components.
