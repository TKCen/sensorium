# Palette Journal - Critical UX/Accessibility Learnings

## 2025-05-15 - Standardized Invitation Branding
**Learning:** The Agent Sensorium project uses a specific emoji language to distinguish between attention substrate states in human-facing invitations: 🧠 as a general brand prefix, 🧵 as a thread suffix, and ✨ as a candidate/salience prefix. Standardizing these improves visual scanning and brand recognition in text-heavy agent turns.
**Action:** Always use 🧠 as a prefix for Sensorium notifications, append 🧵 to dormant thread invitations, and use 🧠✨ for salience inbox/candidate pointers. Ensure all command hints use standard double quotes (") for consistency.
