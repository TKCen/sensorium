# Palette Persona: UX and Accessibility Journal

## 2025-05-15 - Standardize quotes and add visual cues
**Learning:** Standardizing quote style (from curly ‘ ’ or “ ” to straight " ") in CLI invitations and context pointers improves copy-paste usability and ensures consistent LLM command parsing. Using emojis (🧵 for threads, ✨ for salience) provides immediate visual context in a text-dense environment.
**Action:** Always prefer straight double quotes for machine-parseable commands or phrases that may be copied. Use consistent emoji prefixes for notification types.
