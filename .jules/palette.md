# Palette Journal - UX & Accessibility Learnings

## 2026-06-29 - Standardize invitation quotes and visual cues

**Learning:** Standardizing quote style from curly ( ‘ ’ or “ ” ) to straight ( " ) in CLI invitations and context pointers improves copy-paste usability for developers and ensures consistent LLM command parsing. Using thematic emojis (🧠, 📡, 🧵, ✨) significantly improves the scannability of dense status outputs.

**Action:** Always prefer standard double quotes for text/commands in user-facing strings. Use established project emojis as visual landmarks in status reports.
