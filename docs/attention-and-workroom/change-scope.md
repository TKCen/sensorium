# Change scope and verification contract

This candidate implements three attention changes and documents a native/workroom **proposal**. It does not ship a new native owner/runtime framework. Source algorithms inform that proposal, but local source presence is not portable SDK support or runtime approval. [Architecture](architecture.md), [rationale](design-rationale.md) and [migration](migration.md) are self-contained design references.

## Retained protections

The canonical admission foundation rejects ambiguous candidate/advisory authority, preserves malformed joins without projection filtering and constructs uniqueness indexes once per immutable snapshot. Unique uncertain candidates may retain legacy first consideration, never a fresh producer revision. Existing quadratic prior scans and measured SQL work are not a new hard execution budget. Tools ingress (B) now classifies canonical claims and complete typed event joins before replay or effects, rejecting wrapper collisions and ambiguous replay descendants. Its local implementation requires independent acceptance; lineage visibility policy (C) remains held and unchanged. No cache/schema, fingerprint protocol or observer contract is changed by B.

- **Instance/config/store/live/admin:** canonical instance validation before effects, no live arbitrary state-root injection, small ordinary tool surface, explicit admin and generic configurable profiles.
- **Admission/current attention:** source authority and anti-paraphrase suppression, unresolved/held eligibility, bounded attempts and exact index/completeness owners; no capacity-burn projection/window remapping restored.
- **Aperture/doorway/pointers/consumer:** exact lease/generation/consumer/presentation settlement, stale reclaim without fabricated semantic resolution, future HELD checkpoints, STOP and session-local pointers.
- **Live turn/memory/reflection/advisory:** closed surfaces, source observation time, evidence-cited confidence-not-authority and default-OFF configured advisory; no attention-driven memory write permission.
- **Outbox/actions/artifacts/reach-out:** source-bound prepare/decision/delivery owners, held local artifacts and explicit receipt/policy/adapter gates. A workroom checkpoint cannot inherit delivery/task authority.
- **Sensors/improvement/settlement/workers:** deterministic sensing, source-causal feedback, configurable reviewers, synchronized observer evidence and bounded worker recovery.
- **Dashboard/API/frontend/HTTP:** GET-only compact safe labels, hidden bodies, closed profile/artifact access, honest unknown states, derived relation evidence and validated URL/host/parser boundaries; no second control plane.
- **CLI/rollout/clock/consumer/CI/tests/packaging:** preserve canonical ownership, recovery, synthetic regression fixtures and bounded tests. Inherited files are not installation/adoption authority. Public license attribution remains intact.

Wiki world-model integration remains **security-held**, including inherited modules/tests. No Wiki data/configuration, approved reference substitution or adoption is admitted. Gateway compatibility is independently held; neither hold disappears when attention tests pass.

## Observed behavior versus proposed improvements

Source inspection supports strict schemas/identity checks, owner-bound recovery, read-only lifecycle wrappers, finite private artifacts, locks/replay/precharge and consume-once package algorithms. It also identifies nonportable assumptions: source imports may read deployment bindings; initialization imports prior accounting; source reads do not themselves compare an approved manifest; quota is not checked by the request hook; failed reads count only on successful return; standing and standalone continuation admission take different paths; multi-write debit/replay can crash partially; leader reaping and queued STOP do not prove full retirement or active cancellation.

The proposal therefore adds inert generic import, explicit source approval, request-time quota, failed-read preconsumption, durable journal/migration, shared lifetime episode cap and whole-tree/exact-claim cancellation proofs. These are substantive changes requiring implementation and regression evidence, not existing guarantees disguised as generalized paths. Configurable finite limits and externally supplied authoritative provenance avoid making private tuning or a new global registry compulsory.
